# Anchored Impact Receipts (AIR)

Wire type: `ar.impact.v1`

Records DPIA and prior-consultation lifecycle. Eleven event types from threshold triggering through DPO advice, stakeholder consultation, completion, review, and terminal authorisation/blocking. Designed for GDPR Arts. 35-36.
