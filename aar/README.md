# Anchored Attestation Receipts (AAR)

Wire type: `ar.attestation.v1`

Records qualified trust service issuance and revocation. Two event types: `issuance` and `revocation`. Eight eIDAS profiles with TSL snapshot evidence. Designed for eIDAS Arts. 22, 25, 32-34 and relevant ETSI standards.

## Reference Implementation

- Verifier: [`@dekimuhq/aar-verifier`](https://github.com/dekimuhq/aar-verifier)
- Issuer kit: [`@dekimuhq/aar-issuer-kit`](https://github.com/dekimuhq/aar-issuer-kit)
- Profiles: [`@dekimuhq/aar-profiles`](https://github.com/dekimuhq/aar-profiles)
