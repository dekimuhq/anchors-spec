# Anchored Lineage Receipts (ALR)

Wire type: `ar.lineage.v1`

Records data-derivation lineage and disclosure chains. Four event types: `derived_from`, `forked_from`, `superseded_by`, `disclosed`. Five regulatory profiles covering GDPR Art. 13 transparency and AI Act Art. 53 GPAI training data provenance.
