# Anchored Subject-Rights Receipts (ASR)

Wire type: `ar.subject_rights.v1`

Records data-subject rights requests across the GDPR Arts. 15/16/17/18/20/21 lifecycle. Nine event types from request receipt through fulfilment, refusal, or escalation. Six regulatory profiles.
