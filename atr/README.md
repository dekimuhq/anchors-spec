# Anchored Transfer Receipts (ATR)

Wire type: `ar.transfer.v1`

Records cross-border transfer of personal data. Four event types: `arrangement`, `transfer`, `tia` (transfer impact assessment), `suspension`. Eight GDPR/Schrems II profiles. Designed for GDPR Chapter V.
