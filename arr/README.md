# Anchored Retention Receipts (ARR)

Wire types: `ar.erasure.v1`, `ar.expiry.v1`, `ar.hold.v1`, `ar.anonymization.v1`, `ar.archive.v1`, `ar.batch.v1`

Records the full data-retention lifecycle: scheduled deletion, legal holds, anonymization, archival, and batch processing. Designed for GDPR Art. 5(1)(e), Art. 17, and Art. 12(3) compliance.
