# Anchored Evaluation Receipts (AER)

Wire type: `ar.evaluation.v1`

Records AI conformity assessment and transparency obligations. Two event types: `conformity` and `transparency`. Nine regulatory profiles covering AI Act Arts. 43, 50, 52 and NIST AI RMF.
