# Anchored Purpose Receipts (APuR)

Wire type: `ar.purpose.v1`

Records purpose binding and secondary-use controls. Three event types: `purpose.binding`, `purpose.repurpose`, `purpose.unbinding`. Designed for GDPR Art. 5(1)(b) and Art. 30 RoPA.
